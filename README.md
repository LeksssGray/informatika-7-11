## Что нужно перед началом

**Google-аккаунт.** Тот же, что для почты. Без него страницы можно только читать — кнопки запуска не работают. Если аккаунта нет, в первом уроке 5–6 и 7 классов есть пошаговая инструкция, как его завести (и что делать, если ученику меньше 13 лет).

**Предупреждение при открытии.** Colab покажет: «этот блокнот создан не в Google, он может запрашивать доступ к вашим данным». Так он встречает любой чужой файл. Нужно нажать «Всё равно выполнить» (*Run anyway*). Код уроков открыт и лежит в этом репозитории — посмотреть можно всё.

**Своя копия.** «Файл → Сохранить копию на Диске», иначе работа не сохранится: исходные файлы общие.

## Ученику

1. Открой урок по ссылке из оглавления.
2. В первой ячейке впиши имя и класс и запусти её (Shift + Enter). Colab попросит разрешение на доступ к аккаунту — так проверка понимает, чья это работа.
3. Читай, пробуй примеры, решай задачи. В первых уроках ответы вписываются в поле, как в анкете; код начнёшь писать позже.
4. В конце запусти последнюю ячейку — результат уйдёт учителю.

Чтобы сохранить свои решения, выберите **Файл → Сохранить копию на Диске**. Без этого правки пропадут при закрытии вкладки.
