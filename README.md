## Ученику

1. Откройте урок по ссылке из оглавления — установить ничего не нужно, всё работает в браузере.
2. В первой ячейке впишите ФИО и класс и запустите её (Shift + Enter). Colab попросит разрешение на доступ к аккаунту — так подтверждается, кто именно решает задачи.
3. Читайте теорию, запускайте примеры, решайте задачи. Проверка встроена: она сразу показывает, какой тест не прошёл и с какими аргументами.
4. В конце запустите последнюю ячейку — результат уйдёт учителю.

Чтобы сохранить свои решения, выберите **Файл → Сохранить копию на Диске**. Без этого правки пропадут при закрытии вкладки.

## Учителю

Результаты автопроверки собираются в Google-таблицу: кто, когда, какую задачу решил, с какой попытки и каким кодом.

Исходники уроков, ноутбуки с решениями и инструкция по настройке журнала находятся в отдельном приватном репозитории.

## Как устроен урок

| Этап | Время |
|---|---|
| Разбор теории | 15 мин |
| Примеры с разбором | 10 мин |
| Задачи в классе | 12 мин |
| Выдача домашнего задания | 3 мин |

Домашнее задание — три задачи примерно на 30–40 минут самостоятельной работы.
