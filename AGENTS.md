## Работа в Codex

Локальные навыки находятся в `.agents/skills/`, если установлены. Подбор и перенос
навыков — через библиотеку `E:/projects/AI`; не устанавливать весь набор без нужды.
Старые инструкции Claude хранятся в `old/claude-2026-11-03/` только для восстановления,
не использовать их как активные правила. Архивы old исключать из обычного поиска
и индексации; обращаться к ним только для восстановления или явного сравнения.
При неясностях, влияющих на результат, сначала задать вопрос пользователю.
