# Планирование для ЭлЖур

Отдельные файлы `planirovanie_5_klass.xls` — `planirovanie_11_klass.xls`
подготовлены по структуре `planirovanie_new.xls`: № п\п, тема, количество
часов, домашнее задание. Лист с данными называется `Planirovanie`.

В каждом плане 34 урока по одному часу и четыре раздела по четвертям.
Темы, порядок уроков и домашние задания перенесены из оглавлений
`klass-*/index.ipynb`. Для 5 и 6 классов использован общий курс
`klass-05-06`; содержание этих двух файлов одинаковое.

Файлы предназначены для импорта в раздел планирования ЭлЖур отдельно
для каждого класса. Даты не добавлены: в исходном шаблоне их нет.
Загрузка в аккаунт ЭлЖур не выполнялась.
